# HostCardGlassBoard · 人物竖卡玻璃流程板

效果库 → **场景 · 运镜 → HostCardGlassBoard**。展示名称与源码文件 `HostCardGlassBoard.tsx` 一致。新增到时间轴默认 6.6 秒，`kind` 为 `host-card-glass-board`，继续使用 overlay JSON `version: 1`。

迁自 `dev/host-card-glass-board.tsx` 的 Remotion 动画，用当前项目的 React 卡片与时间轴实现，无新增运行依赖。保留 9:16 人物框、左轴 3D 玻璃板、单次扫光、标题逐字解糊、统一 pop 和箭头连接。场景入退场参考 FocusCard：人物从全屏缩入竖卡，玻璃板由右下方翻入至 −10°；收尾时板面向右上方收走，人物再展开回全屏。去掉示例水印及四角装饰。

## 使用

- `hostSrc`：在面板上传人物视频或图片。优先于兼容参数 `camSrc` 和全局 `doc.cam`；全部留空时显示剪影占位。视频按整条时间轴的绝对秒数对位，暂停、拖动与导出一致；短素材结束后停在末帧。
- `tag / title / en / result`：板头小字、主标题、英文行、结果胶囊。
- `steps`：2–4 步，面板每行填写 `图标或图片路径|名称|副标`。也兼容原始 `{ icon, label, sub }[]` 数组及其 JSON 文本；图标可用本地 logo 路径。四步自动缩窄，不越过板边。
- `tileAt`：逗号分隔的秒数或数字数组，相对本卡 `start`。按口播词锚填写；相邻步骤至少留一次 pop 的时间。两端 tile 均落定后连接线才长，结果等所有连线完成。
- `resultAt`：期望结果出现时间，默认 4.1；默认三步实际在 4.3 秒起出现，因为末条连线需先完成。
- `theme`：`dark` 为玻璃材质，`light` 为白卡、细线、pastel 步骤块和单一板影；`accent` 可填六位十六进制色值。
- `studio`：默认 `true`，像 FocusCard 一样用整屏演播室背景接管场景，深浅随材质主题切换。使用人物素材（含全局口播）时始终铺底，旧卡保存的 `false` 也会自动修正，避免原片人物透过板面。只有无人物素材且显式关闭时才保留透明底。背景固定覆盖全画布，不受卡片缩放、位移和内容退场影响；同样烤入导出。编辑台在这段场景内隐藏底层全屏视频的画面（保留时钟与声音），背景外扩 4px 后由画布裁切，避免非整数预览缩放产生边缘细缝。
- 通用大小、位移、动画速度正常生效。动画速度调整动作时长；词锚保持按秒对齐。卡片太短时会整体压缩编排以保证结果可见，严格对词时应加长卡片。

默认人物在 0.05–1.05 秒从全屏缩入竖卡，板面在 0.35–1.1 秒翻入。末尾预留约 1.05 秒：板面先淡出并收走，人物随后展开，在卸载前回到无圆角的全屏画面；没有人物素材时，剪影改为左右滑入滑出。动画倍速和短卡会压缩这些动作，步骤和结果仍在退场前完成。全屏端点不受卡片缩放、位移影响，背景始终遮住底层原片，避免重影。落定后不漂浮，即使打开全局呼吸感也保持静止。字幕和其他卡片应避开人物框；建议本卡独占场景。

## 素材与导出

编辑台提前 2 秒挂载人物视频进行加载和定位，未到卡片起点时不显示。首帧就绪后才隐藏全屏原片并接管场景；冷加载、快速拖动或素材尚未就绪时保留原片兜底，不出现空底。播放时使用原生视频播放，时间偏差超过 0.25 秒才校正；暂停、拖动时精确定位，尚未完成的 seek 不被每帧打断，完成后只处理最新位置。动画速度参数只影响动效，不改变口播素材的播放速度。

导出继续使用预抽帧图片；组件首次挂载就提供对应绝对时间的图片，提前挂载期间保持透明，避免切入时空一帧。

推荐上传浏览器能直接解码的 H.264 MP4；透明人物用 VP8/VP9 alpha WebM。MOV 是否能预览取决于浏览器解码支持。素材应使用上传后的本地路径，远程视频不能直接由当前本地抽帧流程读取。

新卡的人物视频使用保留 alpha 的 PNG 抽帧，原有卡片仍可使用 JPEG 缓存；导出图片清单兼容旧格式。图片、logo 路径需确保能被导出页面读取。

当前整个编辑台与导出器固定为 **1920×1080 横屏**，原作像素以 2 倍映射。组件的布局函数已支持竖画布上 40% 人物、下 60% 板且取消 rotateY，但应用尚无 9:16 输出入口，本次不改变全局画布协议。

## overlay JSON 示例

```json
{
  "version": 1,
  "cards": [{
    "id": "workflow",
    "kind": "host-card-glass-board",
    "start": 0,
    "end": 6.6,
    "params": {
      "hostSrc": "",
      "tag": "WORKFLOW · 工作流",
      "title": "口播工作流",
      "en": "SCRIPT → VOICE → RENDER",
      "steps": [
        { "icon": "✎", "label": "文稿", "sub": "SCRIPT" },
        { "icon": "◉", "label": "配音", "sub": "VOICE" },
        { "icon": "▶", "label": "成片", "sub": "RENDER" }
      ],
      "tileAt": [1.6, 2.5, 3.4],
      "result": "从想法到成片",
      "theme": "dark",
      "studio": true
    }
  }]
}
```

## 验证

在 `motion-playground/` 执行常规 `npm run build`、`npm run lint`、`npm run check:cards`。启动开发服务器后运行：

```sh
node scripts/check-host-board.mjs http://127.0.0.1:5177
node scripts/check-host-preview.mjs http://127.0.0.1:5177
```

检查 2–4 步、不同时长/倍速的先落定后连线、结果可见、前后定位一致、静止保持、人物连续缩入和展开、缩放位移后的全屏端点、原片遮挡、人物安全区与四步不溢出，并在临时目录保存深浅主题及过渡截图。

播放回归会临时生成长关键帧间隔的视频并延迟人物素材请求，检查冷入场兜底、提前加载但不提前显示、连续播放帧率、暂停、快速往返定位、退场，以及 `?export=1` 的首帧图片。需要 ffmpeg，结束后自动清理测试素材。
